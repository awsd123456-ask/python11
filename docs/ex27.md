## 🎯 初学者提示

### 真值表

#### NOT（非）
| 表达式 | 结果 |
|--------|------|
| not True | False |
| not False | True |

#### OR（或）
| 表达式 | 结果 |
|--------|------|
| True or True | True |
| True or False | True |
| False or True | True |
| False or False | False |

#### AND（与）
| 表达式 | 结果 |
|--------|------|
| True and True | True |
| True and False | False |
| False and True | False |
| False and False | False |

### 记忆技巧

- **NOT**: 取反，真变假，假变真
- **OR**: 有真则真，全假才假
- **AND**: 全真才真，有假则假
