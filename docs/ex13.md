# 练习13: 参数、解包、变量

## 📝 练习目标

学习通过命令行参数传递变量给脚本

## 💻 代码示例

```python
#coding:utf-8
from sys import argv

script, first, second, third = argv

print "The script is called :", script
print "Your first variable is :", first
print "Your second variable is :", second
print "Your third variable is :", third
```

## 🎯 初学者提示

### 重要概念

1. **argv (Argument Variable)**
   - argv 是"参数变量"的缩写
   - 包含运行脚本时传入的所有参数
   - 第一个参数永远是脚本名称本身

2. **解包 (Unpacking)**
   ```python
   script, first, second, third = argv
   ```
   - 将 argv 中的4个值分别赋给4个变量
   - 参数数量必须匹配，否则报错

3. **导入模块**
   ```python
   from sys import argv
   ```
   - `sys` 是系统模块
   - `argv` 是其中的一个功能
   - 只导入需要的部分

### 运行方式

**正确运行:**
```bash
python ex13.py first 2nd 3rd
```

**输出:**
```
The script is called : ex13.py
Your first variable is : first
Your second variable is : 2nd
Your third variable is : 3rd
```

**错误示例:**
```bash
python ex13.py first 2nd
# 报错: 参数不够，需要4个参数（包括脚本名）
```

### 常见问题

1. **参数数量不匹配**
   - 解决: 确保命令行参数数量与代码中变量数量一致

2. **参数包含空格**
   - 使用引号: `python ex13.py "hello world" test`

3. **忘记传参数**
   - 直接运行 `python ex13.py` 会报错

### 练习建议
- 尝试传递不同数量的参数，观察错误信息
- 修改代码接收更多或更少的参数
- 尝试传递包含空格的参数（用引号包裹）
- 思考 argv 和 raw_input() 的区别和使用场景
