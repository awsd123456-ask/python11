# 练习19: 函数和变量

## 📝 练习目标

理解函数参数的多种传递方式

## 💻 代码示例

```python
#coding:utf-8
# 奶酪和饼干
def cheese_and_crackers(cheese_count, boxes_of_crackers):
    print "You have %d cheeses!" % cheese_count
    print "You have %d boxes_of_crackers!" % boxes_of_crackers
    print "Man that's enough for a party!"
    print "Get a blanket.\n"

print u"We can just give the function numbers directly（直接的）:"
cheese_and_crackers(20, 30)

print "OR, we can use variables from our script:"
amount_of_cheese = 10
amount_of_crackers = 50

cheese_and_crackers(amount_of_cheese, amount_of_crackers)

print "We can even do math inside too:"
cheese_and_crackers(10 + 20, 5 + 6)

print u"And we can combine(结合) the two, variables and math:"
cheese_and_crackers(amount_of_cheese + 100, amount_of_crackers + 1000)
```

## 📚 作者学习笔记

**重要提示**: 函数里的变量和脚本里的变量之间没有联系

可以用以下几种方式进行传参（给函数赋值）

## 🎯 初学者提示

### 重要概念

1. **函数参数的作用域**
   ```python
   x = 10  # 脚本变量
   
   def my_function(x):  # 函数参数
       print x  # 这个x是函数参数，不是脚本变量
   
   my_function(20)  # 输出: 20
   print x  # 输出: 10（脚本变量未改变）
   ```

2. **四种传参方式**

   **方式1: 直接传递数字**
   ```python
   cheese_and_crackers(20, 30)
   ```
   - 最直接的方式
   - 适合固定值

   **方式2: 使用变量**
   ```python
   amount_of_cheese = 10
   amount_of_crackers = 50
   cheese_and_crackers(amount_of_cheese, amount_of_crackers)
   ```
   - 代码更易读
   - 值可以复用

   **方式3: 使用表达式**
   ```python
   cheese_and_crackers(10 + 20, 5 + 6)
   ```
   - 先计算表达式
   - 再传递结果

   **方式4: 混合使用**
   ```python
   cheese_and_crackers(amount_of_cheese + 100, amount_of_crackers + 1000)
   ```
   - 变量和运算结合
   - 最灵活的方式

### 参数传递的本质

```python
# 这三种调用是等价的
cheese_and_crackers(30, 56)
cheese_and_crackers(10 + 20, 50 + 6)

x = 30
y = 56
cheese_and_crackers(x, y)
```

**原理**: Python 先计算参数的值，然后传递给函数
