            print line

        print self.name

## 🎯 初学者提示

### 类的基本结构

```python
class ClassName(object):
    
    def __init__(self, parameters):
        # 初始化方法，创建对象时自动调用
        self.attribute = parameters
    
    def method(self):
        # 类的方法
        pass
```

### 关键概念

1. **类（Class）**：对象的模板/蓝图
2. **对象（Object）**：类的实例
3. **self**：指向对象自身的引用
4. **__init__**：构造函数，初始化对象

### 创建和使用对象

```python
# 创建对象
obj = ClassName(arguments)

# 调用方法
obj.method()

# 访问属性
print obj.attribute
```

### 类 vs 函数

| 特性 | 函数 | 类 |
|------|------|-----|
| 用途 | 执行特定任务 | 封装数据和行为 |
| 状态 | 无状态 | 有状态（属性） |
| 调用 | `function()` | `object.method()` |
