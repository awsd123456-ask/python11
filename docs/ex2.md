# 练习2: 注释和井号

## 代码示例

```python
#coding:utf-8
# 这是注释的意思(#号后面加一个空格好看很多)
# 任何在'#'后面的东西都不会被python识别
print "I could have code like this." # 在代码的后面注释
# 打印"This won't run."
print "This won't run."
```

## 学习笔记

- `#` 号用于添加注释
- 任何在 `#` 后面的内容都不会被 Python 执行
- 注释可以写在代码行的末尾
- `#` 号后面加一个空格会更美观
- **重要技巧**: 倒着读代码有助于找错误

## 运行结果

```
I could have code like this.
This won't run.
```
