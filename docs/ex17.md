# 练习17: 更多文件操作

## 📝 练习目标

编写一个Python脚本实现文件复制功能

## 💻 代码示例

```python
#coding:utf-8
from sys import argv
from os.path import exists

script, from_file, to_file = argv

print "Copying from %s to %s" % (from_file, to_file)

# we could do these two on one line too, how?
in_file = open(from_file)
indata = in_file.read()

print "The input file is %d bytes long" % len(indata)

print "Does the output file exist? %r" % exists(to_file)
print "Ready , hit RETURN to continue, CTRL-C to abort."
raw_input()

out_file = open(to_file, 'w')    # 这里需要注意下写的模式下不可以读
out_file.write(indata)

print "Alright, all done."

out_file.close()
in_file.close()
```

## 📚 作者学习笔记

- 写模式 `'w'` 下不可以读取文件
- 可以将两行代码合并为一行

## 🎯 初学者提示

### 重要概念

1. **os.path.exists() 函数**
   ```python
   from os.path import exists
   
   if exists("file.txt"):
       print "文件存在"
   else:
       print "文件不存在"
   ```
   - 检查文件或目录是否存在
   - 返回 True 或 False

2. **文件大小**
   ```python
   data = file.read()
   size = len(data)  # 字节数
   ```

3. **代码优化**
   
   **原代码（两行）:**
   ```python
   in_file = open(from_file)
   indata = in_file.read()
   ```
   
   **优化后（一行）:**
   ```python
   indata = open(from_file).read()
   ```

4. **用户确认机制**
   ```python
   raw_input()  # 等待用户按回车
   ```
   - 给用户思考的时间
   - 防止误操作

### 完整的文件复制流程

```
1. 打开源文件（只读）
   ↓
2. 读取全部内容到内存
   ↓
3. 检查目标文件是否存在
   ↓
4. 等待用户确认
   ↓
5. 打开目标文件（写入模式）
   ↓
6. 写入内容
   ↓
7. 关闭两个文件
```

### 更好的实现方式

**使用 with 语句（推荐）:**
```python
with open(from_file) as in_file:
    with open(to_file, 'w') as out_file:
        out_file.write(in_file.read())
# 文件自动关闭
```

**使用 shutil 模块（最简单）:**
```python
import shutil
shutil.copy(from_file, to_file)
```
