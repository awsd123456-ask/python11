# 练习18: 命名、变量、代码、函数

## 📝 练习目标

学习如何创建和使用函数

## 💻 代码示例

```python
#coding:utf-8
# this one is like your scripts with argv
def print_two(*args):
    arg1, arg2 = args
    print "arg1: %r, arg2: %r" % (arg1,arg2)
# 这里需要注意，用四个空格
	
# ok,that *args is actually pointless(无意义),we can just do this
def print_two_again(arg1, arg2):
	print "arg1: %r, arg2: %r" % (arg1, arg2)
	
# this just takes one argument(参数)
def print_one(arg1):
    print "arg1: %r" % arg1

# this one takes no arguments
def print_none():
    print "I got 'nothin'."

print_two("Zed","Shaw")
print_two_again("Zed","Shaw")
print_one("First!")
print_none()
```

## 📚 作者学习笔记

### 创建函数的步骤
1. 首先用 `def` 命令创建一个函数
2. 起函数名
3. 加上 `()` 里面写上参数
4. 用 `:` 结束本行
5. **注意！** 冒号下面用4个空格缩进的行都是属于这个函数的内容

## 🎯 初学者提示

### 重要概念

1. **函数定义的基本格式**
   ```python
   def 函数名(参数1, 参数2):
       函数体（缩进4个空格）
       return 返回值（可选）
   ```

2. **三种参数形式对比**

   **方式1: *args（不推荐）**
   ```python
   def print_two(*args):
       arg1, arg2 = args
       print arg1, arg2
   ```
   - `*args` 收集所有参数到一个元组
   - 需要手动解包
   - 代码冗余

   **方式2: 直接列出参数（推荐）**
   ```python
   def print_two_again(arg1, arg2):
       print arg1, arg2
   ```
   - 清晰明了
   - 参数数量固定
   - 最常用的方式

   **方式3: 无参数**
   ```python
   def print_none():
       print "I got nothin'."
   ```

3. **函数调用**
   ```python
   # 定义函数
   def greet(name):
       print "Hello, " + name
   
   # 调用函数
   greet("Alice")  # 输出: Hello, Alice
   ```

### 函数的四个要素

| 要素 | 说明 | 示例 |
|------|------|------|
| **def** | 定义关键字 | `def` |
| **函数名** | 标识符，遵循命名规范 | `print_two` |
| **参数** | 括号内，可以有0个或多个 | `(arg1, arg2)` |
| **函数体** | 缩进的代码块 | `print arg1` |

### 运行结果

### 常见错误

1. **忘记缩进**
   ```python
   def my_function():
   print "Hello"  # 错误！需要缩进
   ```

2. **忘记冒号**
   ```python
   def my_function()  # 错误！缺少冒号
       print "Hello"
   ```

3. **参数数量不匹配**
   ```python
   def add(a, b):
       return a + b
   
   add(1)  # 错误！缺少一个参数
   ```
