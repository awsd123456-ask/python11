## 🎯 初学者提示

### while循环基本语法

```python
while 条件:
    执行代码块
    更新条件变量  # 重要！避免无限循环
```

### while vs for

| 特性 | while | for |
|------|-------|-----|
| 循环变量 | 需要手动定义和更新 | 自动管理 |
| 使用场景 | 不确定循环次数 | 确定循环次数 |
| 风险 | 容易造成无限循环 | 相对安全 |

### 避免无限循环

```python
i = 0
while i < 10:
    print i
    i = i + 1  # 必须更新i，否则无限循环
```

### 何时使用while

- 等待用户输入直到满足条件
- 游戏主循环
- 服务器持续监听
- 不确定需要循环多少次的情况
