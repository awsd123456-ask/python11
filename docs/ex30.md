# 练习30: Else 和 If

## 📝 练习目标

学习 if-elif-else 条件判断语句

## 💻 代码示例

```python
#coding:utf-8
people = 30
cars = 40
buses = 15

if cars > people:
    print "We should take the cars."
elif cars < people:
    print "We should not take the cars."
else:
    print "We can't decide."
    
if buses > cars:
    print "That's too many buses."
elif buses < cars:
    print "Maybe we could take the buses."
else:
    print "We still can't decide."
    
if people > buses:
    print "Alright,let's juset take the buses."
else:
    print"Fine ,let's stay home then."
    
if people > cars and people >buses:
    print u"没车可作！"
elif people < cars:
    print u"做car"
else:
    print u"做bus"
```

## 📚 作者学习笔记

- 四个空格的意思就是：缩进块
- 可以使用 `and` 连接多个条件

## 🎯 初学者提示

### if-elif-else 结构

```python
if 条件1:
    执行代码块1
elif 条件2:
    执行代码块2
else:
    执行代码块3
```

### 逻辑运算符
- `and` - 与
- `or` - 或
- `not` - 非
