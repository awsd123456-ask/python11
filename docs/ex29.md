# 练习29: if语句

## 📝 练习目标

学习使用if语句进行条件判断

## 💻 代码示例

```python
#coding:utf-8
people = 20
cats = 30
dogs = 15


if people < cats:
    print "Too many cats! The world is doomed!"
 
if people > cats:
    print "Not many cats! The world is saved!"
    
if people < dogs:
    print "The world is drooled on!"    # 流口水
    
if people > dogs:
    print "The world is dry!"
    
    
dogs += 5

if people >= dogs:
    print "People are greater than or equal to dogs."
    
if people <= dogs:
    print "People are less than or equal to dogs."
    
if people == dogs:
    print "People are dogs."
```

## 🎯 初学者提示

### if语句基本结构

```python
if 条件:
    执行的代码块
```

### 比较运算符

```python
<   # 小于
>   # 大于
<=  # 小于等于
>=  # 大于等于
==  # 等于
!=  # 不等于
```

### 注意事项

1. **缩进很重要**：if语句后的代码块必须缩进（通常4个空格）
2. **冒号不能忘**：if语句末尾必须有冒号 `:`
3. **条件表达式**：条件可以是任何返回布尔值的表达式
