# 练习1: 第一个程序

## 代码示例

```python
#coding:utf-8
print "hello Word!"
print  u"你好？"
print "你好?"#在linux系统下不需要加u
print "Heloo Again"
print "I like typing this."
print "This is fun."
print 'Yay! Printing.'
print "I'd much rather you 'not'."
print 'I "said" do not touch this.'
```

## 学习笔记

- 输出中文的时候要在字符串前面加 `u`
- 因为 Python 中字符串默认采用 ASCII，要声明为 unicode 就要加 `u`（Linux 环境下不需要加 `u`）
- `print` 语句可以输出字符串
- 单引号和双引号都可以用来定义字符串
