# 练习34: 访问列表的元素

## 📝 练习目标

深入理解列表索引，掌握如何访问列表中的元素

## 💻 代码示例

```python
#coding:utf-8
animals = ['bear', 'python', 'peacock', 'kangaroo', 'whale', 'platypus']

# 访问不同位置的元素
print "The 1st animal is at 0 and is a", animals[0]
print "The 2nd animal is at 1 and is a", animals[1]
print "The 3rd animal is at 2 and is a", animals[2]
print "The 4th animal is at 3 and is a", animals[3]
print "The 5th animal is at 4 and is a", animals[4]
print "The 6th animal is at 5 and is a", animals[5]

# 使用负数索引从后往前访问
print "The last animal is at -1 and is a", animals[-1]
print "The 2nd to last animal is at -2 and is a", animals[-2]
```

## 🎯 初学者提示

### 列表索引规则

```python
列表 = ['a', 'b', 'c', 'd', 'e']
索引   [0,   1,   2,   3,   4]
负索引 [-5, -4,  -3,  -2,  -1]
```

### 正向索引（从0开始）

```python
animals[0]  # 第1个元素
animals[1]  # 第2个元素
animals[2]  # 第3个元素
```

### 反向索引（从-1开始）

```python
animals[-1]  # 最后一个元素
animals[-2]  # 倒数第2个元素
animals[-3]  # 倒数第3个元素
```

### 常见错误

```python
# 索引超出范围会报错
animals[100]  # IndexError: list index out of range

# 记住：第1个元素的索引是0，不是1
animals[1]    # 这是第2个元素，不是第1个
```

### 序数 vs 索引

- **序数**（Ordinal）：第1个、第2个、第3个...（人类习惯）
- **索引**（Index）：0、1、2...（计算机习惯）
- **关系**：第N个元素的索引是 N-1
