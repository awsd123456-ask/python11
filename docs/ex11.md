# 练习11: 提问

## 📝 练习目标

学习如何接收用户的输入

## 💻 代码示例

```python
#coding:utf-8
print "How old are you?",
# 接收控制台的输入信息
age = raw_input()
print "How tall are you?",
height = raw_input()
print "How much do you weight?",
weight = raw_input()

print "So,you're %r old, %r tall and %r heavy." %(
    age, height, weight)
```

## 📚 作者学习笔记

- **raw_input()**: 接受控制台输入的任何信息
- **print 后面加逗号**: 可以让输入在同一行

## 🎯 初学者提示

### 重要概念

1. **raw_input() 函数**
   - 暂停程序，等待用户输入
   - 用户按回车后继续执行
   - 返回的是字符串类型

2. **交互式程序**
   - 程序可以和用户对话
   - 根据用户输入做出响应

3. **print 末尾的逗号**
   - 让提示和输入在同一行
   - 提升用户体验

### 运行示例

```
How old are you? 25
How tall are you? 180cm
How much do you weight? 70kg
So,you're '25' old, '180cm' tall and '70kg' heavy.
```

### Python 2 vs Python 3

**Python 2 (本代码):**
```python
age = raw_input()
```

**Python 3:**
```python
age = input()
```
