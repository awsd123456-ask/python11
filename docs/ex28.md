## 💻 代码示例

```python
#coding:utf-8
man = u"男人"
woman = u"女人"
sex = man == woman
print sex    # 结果是false

print man and woman
print "test1" and "test2"    # 警告：我和书上产生了奇异，我输出的第二个操作数，书中说是第一个
```

## 🎯 初学者提示

### 布尔表达式基础

```python
# 比较运算符
== # 等于
!= # 不等于
>  # 大于
<  # 小于
>= # 大于等于
<= # 小于等于
```

### 逻辑运算符的返回值

在Python中，`and` 和 `or` 不一定返回 `True` 或 `False`：

```python
# and 返回第一个假值，或最后一个值
"test1" and "test2"  # 返回 "test2"
"" and "test2"       # 返回 ""

# or 返回第一个真值，或最后一个值
"test1" or "test2"   # 返回 "test1"
"" or "test2"        # 返回 "test2"
```
