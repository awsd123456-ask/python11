# 练习14: 提示和传递

## 📝 练习目标

结合使用 argv 和 raw_input()，创建交互式脚本

## 💻 代码示例

```python
#coding:utf-8
from sys import argv

script, user_name = argv
prompt = '> '

print "Hi %s, I'm the %s script." % (user_name,script)
print "I'd like to ask you a few questions."
print "Do you like me %s?" % user_name
likes = raw_input(prompt)

print "Where do you live %s?" % user_name
lives = raw_input(prompt)

print "What kind of computer do you have?"
computer = raw_input(prompt)

print """
Alright, so you said %r about liking me .
You live in %r. Not sure where that is.
And you have a %r computer. Nice.
""" % (likes, lives, computer)
```

## 📚 作者学习笔记

- **结合使用**: raw_input 和 argv 两者结合使用

## 🎯 初学者提示

### 重要概念

1. **argv + raw_input 组合**
   - argv: 启动时获取参数
   - raw_input: 运行中获取输入
   - 两者配合使用更灵活

2. **提示符变量**
   ```python
   prompt = '> '
   likes = raw_input(prompt)
   ```
   - 定义统一的提示符
   - 代码更整洁，易于修改

3. **个性化交互**
   - 使用用户名称让对话更友好
   - 程序显得更"智能"

### 运行方式

**命令行:**
```bash
python ex14.py Alice
```

**交互过程:**
```
Hi Alice, I'm the ex14.py script.
I'd like to ask you a few questions.
Do you like me Alice?
> Yes
Where do you live Alice?
> Beijing
What kind of computer do you have?
> MacBook

Alright, so you said 'Yes' about liking me .
You live in 'Beijing'. Not sure where that is.
And you have a 'MacBook' computer. Nice.
```

### 两种输入方式对比

| 方式 | 时机 | 用途 | 示例 |
|------|------|------|------|
| **argv** | 启动时 | 配置参数 | 用户名、文件路径 |
| **raw_input** | 运行中 | 交互输入 | 问答、选择 |
