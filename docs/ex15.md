## 🎯 初学者提示

### 重要概念

1. **文件操作三步骤**
   ```python
   # 1. 打开文件
   txt = open(filename)
   
   # 2. 读取内容
   content = txt.read()
   
   # 3. 关闭文件（重要！）
   txt.close()
   ```

2. **两种获取文件名的方式**
   
   **方式1: 通过 argv**
   ```python
   script, filename = argv
   txt = open(filename)
   ```
   
   **方式2: 通过 raw_input**
   ```python
   filename = raw_input("> ")
   txt = open(filename)
   ```

3. **为什么要关闭文件？**
   - 释放系统资源
   - 确保数据写入完成
   - 避免文件被锁定

### 常见问题

1. **FileNotFoundError**
   - 原因: 文件不存在或路径错误
   - 解决: 确保文件在当前目录，或使用完整路径

2. **读取后再次读取为空**
   ```python
   txt = open(filename)
   print txt.read()  # 有内容
   print txt.read()  # 空的！
   ```
   - 原因: 文件指针已到末尾
   - 解决: 重新打开文件，或使用 `txt.seek(0)`

3. **忘记关闭文件**
   - 可能导致资源泄漏
   - 养成好习惯，用完就关闭

### 更好的写法（Python 推荐）

```python
# 使用 with 语句，自动关闭文件
with open(filename) as txt:
    print txt.read()
# 文件自动关闭，无需手动调用 close()
```
