# 练习12: 提示别人

## 📝 练习目标

学习 raw_input() 带提示信息的用法

## 💻 代码示例

```python
#coding:utf-8
age = raw_input("How old are you? ")
height = raw_input("How tall are you? ")
weight = raw_input("How much do you weight? ")

print "So, you are %r old, %r tall and %r heavy."% (
    age, height, weight)
```

## 📚 作者学习笔记

- **raw_input("提示信息")**: 可以直接在函数中写提示信息

## 🎯 初学者提示

### 重要概念

1. **raw_input() 的两种用法**
   
   **方式1: 分开写（练习11）**
   ```python
   print "How old are you?",
   age = raw_input()
   ```
   
   **方式2: 合并写（本练习）**
   ```python
   age = raw_input("How old are you? ")
   ```

2. **哪种方式更好？**
   - 方式2更简洁，推荐使用
   - 代码更短，更易读
   - 功能完全相同

### 运行示例

```
How old are you? 25
How tall are you? 180cm
How much do you weight? 70kg
So, you are '25' old, '180cm' tall and '70kg' heavy.
```
