## 📚 作者学习笔记

- **\t**: 输出制表符（通常是8个空格）
- **\n**: 换行符
- **\\**: 输出反斜杠本身

## 🎯 初学者提示

### 常用转义字符表

| 转义字符 | 含义 | 示例 |
|---------|------|------|
| `\n` | 换行 | `"第一行\n第二行"` |
| `\t` | 制表符（Tab） | `"\t缩进的文本"` |
| `\\` | 反斜杠 | `"C:\\Users\\Admin"` |
| `\'` | 单引号 | `'I\'m happy'` |
| `\"` | 双引号 | `"He said \"Hi\""` |
| `\r` | 回车（返回行首） | 用于覆盖当前行 |

### 重要概念

1. **为什么需要转义字符？**
   - 某些字符有特殊含义（如引号）
   - 某些字符无法直接输入（如换行）
   - 使用 `\` 来"转义"这些特殊字符

2. **制表符 \t 的作用**
   - 对齐文本
   - 创建缩进
   - 制作简单的表格

3. **反斜杠的双重身份**
   - 单个 `\` 是转义符号
   - `\\` 才能输出反斜杠本身
