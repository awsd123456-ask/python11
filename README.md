## 📚 介绍

这是《笨方法学 Python》的完整学习笔记，包含：
- ✅ 52个练习的完整代码
- ✅ 原作者的学习经验和注释
- ✅ 适合初学者的详细说明
- ✅ 每个练习的运行示例和常见问题

## 🎯 如何使用

### 在线阅读（推荐）
访问 GitBook 在线文档：[开始学习](SUMMARY.md)

### 本地学习
1. 克隆仓库：`git clone https://github.com/awsd123456-ask/python11.git`
2. 查看 `docs/` 目录下的 Markdown 文档
3. 运行 `content/` 目录下的 Python 代码

**笨方法学习法：**
1. 不要只是看代码，要**手动输入**每一行
2. 运行代码，观察结果
3. 阅读学习笔记，理解原理
4. 尝试修改代码，做实验
